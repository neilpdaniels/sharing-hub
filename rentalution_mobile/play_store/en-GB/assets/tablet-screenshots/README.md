# Tablet screenshots

The Play Console requires these assets for this app. You do not need physical
7-inch and 10-inch tablets. Capture four clean
16:10 screenshots at 2,560 × 1,600 px using the Android `medium_tablet`
emulator profile, then upload the same four images to both Play Console
tablet sections.

Keep the screenshots as genuine in-app screens without added promotional
text. Suggested sequence:

1. `01-browse-tablet.png`
2. `02-listing-details-tablet.png`
3. `03-booking-tablet.png`
4. `04-messages-or-account-tablet.png`

Before making the listing assets, check the app's primary journeys at an
8-inch tablet size (1,024 × 640 dp) and a 10.5-inch tablet size
(1,280 × 800 dp) to catch layout issues.
