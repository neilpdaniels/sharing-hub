# Rentalution — Google Play listing (English, United Kingdom)

This is the only Google Play listing locale maintained in the repository.
Set the Play Console's default store-listing language to **English (United
Kingdom)** and do not add translated listings.

## Text

- **App name:** Rentalution
- **Short description (maximum 80 characters):** Rent useful items locally. List, browse and book equipment when you need it.
- **Full description (maximum 4,000 characters):**

  Rentalution is a marketplace for renting useful items locally.

  Browse available items, view listing details and arrange rentals through the
  app. Create listings for items you want to rent out, manage booking requests
  and communicate with other users.

  Availability, prices and rental arrangements are set by the people using the
  platform. Please review listing details and terms before making a booking.

for the initial English-only listing.
